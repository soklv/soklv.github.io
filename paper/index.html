The fixed rules (v1.1)

1. Universe: BTC / USDT, ETH / USDT — real daily closes from a public exchange API (no account, no keys).

2. One evaluation per closed day, in the morning issue (~07:00 Riga). No intraday moves, no discretionary calls.

3. BUY 10% of remaining cash when the 7-day return is above +1% and the close is above its 30-day average; never more than 50% of equity in one asset; skip if less than 10 USDT free.

4. SELL half a position when its 7-day return drops below −5%. Otherwise hold. Fee 0.1% on every fill. Rules v1.1: a position worth under 1 USDT is closed in full instead of being halved forever — real exchanges reject sub-minimum orders.

The same candles in → the same trades out: the engine is deterministic. The full ledger lives in paper/state.json in this site’s repository — every change is a commit, so the git history is the audit trail.

Honest limits

Daily-close fills only: no intraday prices, no slippage, no partial-fill quirks, funding rates not modelled. A position under 1 USDT would not even be accepted by a real exchange — rules v1.1 closes it in full. Real trading would differ. That is exactly why this desk is labelled paper everywhere.
